# knn and nested cross validation

This repository contains a jupyter notebook with code for implemenation of the k-nearest neighbor (kNN) algorithm, nested cross-validation and calculation of evaluation metrics and confusion matrix. 

The notebook has comments throughout so hopefully viewers can follow along.
The kNN algorithm uses lists and dictionaries because the idea was an algorithm that relies only on built-in python functionality without the need to import numpy arrays. 
The nested cross validation and confusion matrix code use numpy arrays.
